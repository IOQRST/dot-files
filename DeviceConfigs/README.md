# Заводим работу ATK F1 Ultimate И AKKO 5075S на Linux.

## Порядок действий:
- Файл [правил](71-atk-hub.rules), не меняя имени нужно закинуть в папку `/etc/udev/rules.d/`.
- Затем перезагрузить правила командой `sudo udevadm control --reload-rules; sudo udevadm trigger`.
- После чего попробовать авторизовать мышку, донгл и клавиатуру.

## Проверка:
- Для авторизации мышки [ATK.HUB](https://hub.atk.pro/).
- Для авторизации клавиатуры - [VIA](https://usevia.app/) (_Нужно отметить, что для того, что бы работала клавиатура именно этой модели, нужен файл с раскладкой. Обычно он поставляется в .json формате. Сначала в настройках VIA нужно включить дизайнер. Затем загрузить файл. И только потом авторизовать устройство._)
