# Конфигурационные файлы, которые лично я использую.

В Этом репозитории можно найти dot-files, которые я использую для настройки своего окружения:

1. sh файлы для полуавтоматической установки archlike дистрибутивов;
2. Конфиг для DoomEmacs;
3. Конфиг для FastFetch;
4. Конфиг и список расширений для FireFox;
5. Конфиг для NeoVim;
6. Темы для Telegram;
7. Список расширений и настройки для VSCodium;
8. Список расширений и настройки для Zed;

В дальнейшем, возможно, будут добавляться/изменяться/удаляться какие-либо файлы/разделы в зависимости от использования.
